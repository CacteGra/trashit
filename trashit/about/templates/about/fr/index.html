À propos de TrashIt

En tirant parti du pouvoir des données ouvertes, TrashIt aide les utilisateurs à trouver le bon endroit pour jeter leurs déchets en cartographiant leur environnement immédiat, à améliorer le recyclage en choisissant la bonne poubelle, et à réduire le déversement illégal de déchets en redirigeant vers les déchetteries les plus proches et en signalant les problèmes locaux.

Cartographie

Obtenez l'élimination des déchets locaux instantanément. Les utilisateurs peuvent également demander que leur zone soit ajoutée (les bots sont filtrés à l'aide d'un simple captcha).

Horaires et dates de ramassage des déchets

Sur demande, les services publics sont ajoutés à la gestion locale.

Indiquer ce qui va où

Les utilisateurs peuvent scanner le code-barres de leur emballage alimentaire pour trouver la bonne poubelle.

Signaler les déversements illégaux de déchets

Envoyez l'emplacement aux services publics locaux par e-mail.

Comment fonctionne l'application ?

Demande d'emplacements locaux de déchetteries

Après approbation manuelle, l'application récupère les données locales (d'abord via OSM, puis l'API locale) en filtrant les bots avec un Captcha.

Utilisation de l'API de données OSM

Appels API globaux spécifiant : ville, état et pays. Collecte de données pour tout type de déchet.

Utilisation de l'API locale/fichier en ligne

Adapté à tout type d'API ou de fichiers (CSV, JSON, KML) avec des options disponibles : pagination, temps de pause.

Pas besoin de parcourir la documentation API.

Données clés

TrashIt renvoie automatiquement un ensemble de colonnes de données avec des exemples pour que les administrateurs puissent choisir.

Itération des données

Une fois sélectionnées, l'application Web enregistre les points de données correspondants.

Itération des données

Itération des lignes de données pour enregistrer les points de données correspondants.
