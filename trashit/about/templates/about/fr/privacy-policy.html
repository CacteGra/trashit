Politique de confidentialité de TrashIt

Date d'effet : [Insérer la date]  |  Dernière mise à jour : [Insérer la date]

Chez TrashIt (accessible via https://trashit.click/), l'une de nos principales priorités est la confidentialité de nos visiteurs. Ce document de Politique de confidentialité contient les types d'informations collectées et enregistrées par TrashIt, ainsi que la manière dont nous les utilisons.

Si vous avez des questions supplémentaires ou si vous souhaitez plus d'informations concernant notre Politique de confidentialité, n'hésitez pas à nous contacter à l'adresse .

1. Informations que nous collectons

Afin de fournir nos services de cartographie, de recyclage et de signalement, nous collectons plusieurs types d'informations.

A. Données de localisation précises

La fonctionnalité principale de l'application web TrashIt repose sur votre localisation géographique.

  • Comment nous les collectons : Nous utilisons l'API de géolocalisation de votre navigateur pour demander vos coordonnées actuelles (latitude et longitude).
  • Comment nous les utilisons : Nous utilisons ces données pour centrer la carte sur votre position, vous montrer les points de collecte des déchets à proximité, fournir les horaires de collecte locaux et vous permettre de signaler des dépôts sauvages à votre emplacement précis.
  • Suivi continu : Veuillez noter que pour une meilleure expérience utilisateur, notre application peut périodiquement actualiser votre position pour mettre à jour la carte pendant que vous vous déplacez.

B. Informations visuelles (Accès à la caméra)

TrashIt inclut des fonctionnalités nécessitant l'accès à la caméra de votre appareil.

  • Numérisation de codes-barres : Nous utilisons votre caméra pour scanner les emballages de produits afin de fournir des instructions de recyclage.
  • Signalement de problèmes : Lors du signalement de dépôts sauvages, vous pouvez choisir de prendre une photographie pour fournir des preuves aux autorités locales.
  • Traitement : Nous n'accédons à votre caméra que lorsque vous activez explicitement ces fonctionnalités (par exemple, en cliquant sur « Scanner un emballage » ou « Signaler des déchets »). Les photos sont traitées pour être envoyées via le client e-mail de votre appareil ou téléchargées sur notre système de signalement, comme indiqué dans l'interface.

C. Données d'utilisation et d'analyse

Nous collectons des données pour comprendre les performances de notre service et améliorer l'expérience utilisateur.

  • Durée de session : Nous utilisons l'API navigator.sendBeacon pour enregistrer le temps passé par un utilisateur sur des pages spécifiques (par exemple, la page d'accueil). Ces données sont utilisées à des fins analytiques anonymes pour comprendre l'engagement.
  • Informations sur le navigateur : Nous pouvons collecter des informations sur la langue de votre navigateur, le type d'appareil et la version du navigateur pour garantir que l'application s'affiche correctement dans votre langue et format locaux.

2. Comment nous utilisons vos informations

Nous utilisons les informations collectées de diverses manières, notamment pour :

  • Fournir, exploiter et maintenir notre application web.
  • Améliorer, personnaliser et développer nos services.
  • Comprendre et analyser la manière dont vous utilisez notre application web.
  • Développer de nouvelles fonctionnalités.
  • Communiquer avec vous, directement ou par l'intermédiaire de nos partenaires, pour le service client ou pour vous fournir des mises à jour concernant notre service.
  • Faciliter le signalement de problèmes environnementaux aux services publics locaux.

3. Services tiers et données ouvertes

TrashIt utilise des technologies tierces pour fournir ses services. Ces tiers peuvent collecter des informations conformément à leurs propres politiques de confidentialité :

  • OpenStreetMap (OSM) : Nous utilisons OpenStreetMap pour nos tuiles cartographiques et nos données. Vos demandes de tuiles incluent votre adresse IP et vos données de localisation dans le cadre des requêtes HTTP standard vers leurs serveurs.
  • Leaflet : Nous utilisons la bibliothèque JavaScript Leaflet pour afficher des cartes interactives.
  • Quagga2 : Nous utilisons cette bibliothèque pour la numérisation de codes-barres via votre caméra.
  • API gouvernementales/locales : Lorsque vous demandez des données locales ou signalez un problème, des informations (telles que votre localisation et potentiellement votre e-mail) peuvent être transmises aux API des services publics locaux ou via votre client e-mail aux autorités compétentes.

4. Conservation des données

Nous conservons les informations collectées uniquement aussi longtemps que nécessaire aux fins décrites dans cette Politique de confidentialité.

  • Données de localisation : La localisation en temps réel est traitée lors de la session pour fournir des services cartographiques et n'est pas stockée de manière permanente sauf si vous soumettez spécifiquement un signalement.
  • Données analytiques : Les données d'utilisation anonymes sont conservées pour nous aider à améliorer les métriques de notre service.

5. Sécurité de vos données

Nous tenons à votre confiance en nous fournissant vos informations. Nous utilisons des méthodes standard de l'industrie (telles que le chiffrement HTTPS/TLS) pour protéger vos données lors de leur transmission. Cependant, veuillez rappeler qu'aucune méthode de transmission sur internet, ni méthode de stockage électronique, n'est sécurisée à 100 %.

6. Informations concernant les enfants

Une autre de nos priorités est d'assurer la protection des enfants sur internet. TrashIt ne collecte pas sciemment d'informations personnelles identifiables auprès d'enfants de moins de 13 ans (ou de l'âge applicable dans votre juridiction). Si vous pensez que votre enfant a fourni ce type d'informations sur notre site, nous vous encourageons vivement à nous contacter immédiatement afin que nous fassions de notre mieux pour supprimer ces informations de nos registres dans les meilleurs délais.

7. Vos droits en matière de protection des données (RGPD/CCPA)

Selon votre localisation, vous pouvez disposer des droits suivants :

  • Le droit d'accès : Vous avez le droit de demander des copies de vos données personnelles.
  • Le droit de rectification : Vous avez le droit de demander la correction de toutes les informations que vous jugez inexactes.
  • Le droit à l'effacement : Vous avez le droit de demander l'effacement de vos données personnelles, sous certaines conditions.
  • Le droit d'opposition au traitement : Vous avez le droit de vous opposer au traitement de vos données personnelles.

8. Modifications de cette politique de confidentialité

Nous pouvons mettre à jour notre Politique de confidentialité de temps à autre. Nous vous conseillons donc de consulter cette page périodiquement pour toute modification. Nous vous informerons de tout changement en publiant la nouvelle Politique de confidentialité sur cette page.
