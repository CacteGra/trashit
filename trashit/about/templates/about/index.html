About TrashIt

Harnessing the power of open data to help users find the right spot to take out their trash by mapping their direct environment, improve recycling with choosing the right garbage can and reduce unauthorized waste dumping by redirecting to closest trashes and reporting local issues.

Mapping

Get local waste disposal in an instant. Users can also request their area to be added (bots are filtered using a simple captcha).

Find out trash pickup time and dates

Upon request, public services are added to local managing.

Tell users what goes where

Users can scan the barcode of their food packaging to find the right garbage.

Report unauthorized waste dumping

Send location to local public services via email.

Filter

Choose the trash type for easier readability on the map.

Free of Charge

For anyone to use.

How The App Works?

Request local trash locations

After a manual approval, the app will get local data (through OSM first, then local API) filtering bots with a Captcha.

Using OSM data API

Global API calls specifying: city, state and country. Collecting data for any type of trash.

Using local API/online file

Adapted for any kind of API or files (CSV, JSON, KML) with options available: pagination, sleep time.

No need to peruse API docs.

Key data

TrashIt automatically returns a set of data columns with examples for admins to choose from.

Data Iteration

Once selected, the web app records matching data points.

Data iteration

Iterating data rows to record matching data points.
