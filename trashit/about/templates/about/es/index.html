Acerca de TrashIt

Aprovechamos el poder de los datos abiertos para ayudar a los usuarios a encontrar el lugar correcto para depositar sus residuos, mapeando su entorno inmediato; mejoramos el reciclaje al elegir el contenedor adecuado y reducimos la vertedura ilegal de residuos redirigiendo hacia los puntos más cercanos y permitiendo reportar incidencias locales.

Mapeo

Obtén la ubicación de puntos de disposición de residuos al instante. Los usuarios también pueden solicitar agregar su zona (los bots se filtran mediante un captcha sencillo).

Consulta horarios y fechas de recogida

A petición, los servicios públicos se integran en la gestión local.

Indica dónde depositar cada residuo

Los usuarios pueden escanear el código de barras de sus envases para saber en qué contenedor depositarlos.

Reporta verteduras ilegales

Envía la ubicación a los servicios públicos locales por correo electrónico.

Filtrar

Selecciona el tipo de residuo para facilitar la lectura en el mapa.

Sin costo

Para uso libre por todos.

¿Cómo funciona la aplicación?

Solicita ubicaciones de recogida

Tras una aprobación manual, la aplicación obtendrá datos locales (primero a través de OSM, luego mediante API local), filtrando bots con un Captcha.

Uso de la API de datos de OSM

Llamadas API globales especificando: ciudad, estado y país. Recopilación de datos para cualquier tipo de residuo.

Uso de API local o archivo en línea

Adaptado para cualquier tipo de API o archivos (CSV, JSON, KML) con opciones disponibles: paginación, tiempo de espera.

No es necesario revisar la documentación de la API.

Datos clave

TrashIt devuelve automáticamente un conjunto de columnas de datos con ejemplos para que los administradores elijan.

Iteración de datos

Una vez seleccionados, la aplicación web registra los puntos de datos coincidentes.

Iteración de datos

Iteración de filas de datos para registrar los puntos coincidentes.

Nuestras opciones de precios

El plan básico es gratuito y está disponible a petición de los residentes para obtener datos de la API de OSM, así como datos abiertos de APIs locales. Para ciudades o aglomeraciones que deseen acceder a funciones de administración, el precio se fija según la población. Contáctanos para resolver dudas o solicitar una cotización personalizada.
